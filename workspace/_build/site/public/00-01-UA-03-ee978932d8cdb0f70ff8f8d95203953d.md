## Módulo 1: Gestión de Almacenamiento y sistema de archivos

::::{grid} 2 2 2 2
:::{card}
:header: Contenidos
1. Concepto de archivo, incluyendo datos, metadatos, operaciones y modo de acceso.
2. Implementación de directorios.
2. Montaje del sistema de archivos
3. Control de acceso a archivos
4. Métodos básicos de asignación de archivos, incluyendo tablas de asignación enlazadas.
5. Sistemas de archivos: particiones, mount/unmount, sistemas de ar-chivos virtuales.

:::

:::{card}
:header: Resultados de aprendizaje
* Conoce las abstracciones que utiliza el sistema operativo para lograr la persistencia de datos en un sistema de almacenamiento.
:::
