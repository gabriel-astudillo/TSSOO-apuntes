Modelo operacional de procesos

Modelo de entradas y salidas¶

Desde el punto de vista del sistema operativo, un proceso tiene entradas y salidas asignadas al momento de su creación (ver Figura 1). La entrada de un proceso se llama Entrada Estándar stdin. Las salidas que tiene asociado un proceso son dos: a) Salida Estándar stdout y b) Salida de errores stderr.

Códigos de término de ejecución¶

Al terminar (esto es, al llegar a una llamada exit()), el proceso informa al sistema operativo el código de terminación. Finalmente, antes de ser creado y cuando es invocado a través, por ejemplo, de una Interfaz de Comandos o CLI es posible pasarlas argumentos al proceso.

Los códigos de términación más utilizadas se muestran en la Figura 3)

Argumentos¶

Desde el punto de vista del sistema operativo, el código de un proceso tiene un punto de entrada que se debe acceder para se pueda ejecutar. Este punto de entrada es la función main() del código y puede recibir los argumentos que fueron ingresados desde la CLI.

int main(int argc, char* argv[]) {
    // arg0 = argv[0] ...
    ...

    exit(EXIT_SUCCESS);
}

Los parámetros de la función main() son dos:

  • argc: argument count.

  • argv: argument value.
