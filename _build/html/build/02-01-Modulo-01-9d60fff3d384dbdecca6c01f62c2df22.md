# Modelo operacional de procesos

Desde el punto de vista del sistema operativo, un proceso tiene entradas y salidas asignadas al momento de su creación (ver {numref}`Figura %s <02-01-entradas-salidas>`). La entrada de un proceso se llama Entrada Estándar `stdin`. Las salidas que tiene asociado un proceso son dos: a) Salida Estándar `stdout` y b) Salida de errores `stderr`. Al terminar (esto es, al llegar a una llamada `exit()`), el proceso informa al sistema operativo el código de terminación.
