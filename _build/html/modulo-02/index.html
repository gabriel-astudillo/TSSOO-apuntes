Qué es un Sistema Operativo¶

Personas: Mary Allen Wilkes (1937 - )

En los años 1959 a 1963, Participó en el proyecto LINC, un dispositivo enfocado en el procesamiento de datos en tiempo real en biomedicina. En ese proyecto, asumió la responsabilidad de escribir todo el software de sistema. Su principal aporte fue LAP6 (LINC Assembly Program 6), un entorno operativo y de programación interactiva Wilkes, 1970 (copia local). Fue el primer sistema operativo que estaba entre el hardware y los programas. (“Pioneers in Tech”). Además, al integrar al sistema LINC un editor de texto que utilizaba una pantalla y teclado, cimentó las bases de interacción con los sistemas de cómputo actuales (ver nota)

Un Sistema Operativo (SO) se define formalmente como la capa de software fundamental que actúa como intermediario crítico entre el hardware subyacente y las aplicaciones de usuario, gestionando de manera eficiente, equitativa y segura los recursos computacionales Silberschatz et al., 2018. Desde la perspectiva de la arquitectura de sistemas, el hardware provee las capacidades físicas primarias —tales como unidades de procesamiento, jerarquías de memoria, subsistemas de almacenamiento y dispositivos de entrada/salida—, mientras que los programas y aplicaciones definen los requerimientos funcionales y de rendimiento. El SO arbitra estas demandas mediante algoritmos de planificación (scheduling), control de concurrencia y políticas de asignación, determinando cómo se utilizan dichos recursos para resolver problemas computacionales complejos en entornos dinámicos.

Para lograr lo anterior, un SO debe proveer un conjunto de abstracciones del hardware a las aplicaciones que se ejecutan en el sistema. Estas abstracciones transforman los componentes físicos en entidades lógicas (por ejemplo, procesos e hilos en lugar de registros de CPU y ciclos de reloj; espacios de direcciones virtuales en lugar de celdas de memoria física; sistemas de archivos en lugar de bloques en discos magnéticos o de estado sólido). Como consecuencia directa de este diseño, distintos Sistemas Operativos definen diferentes modelos de abstracción sobre una misma arquitectura de hardware, priorizando aspectos específicos como el rendimiento en tiempo real, el aislamiento de seguridad, la eficiencia energética o la portabilidad Muralidhar et al., 2022.

Actualmente, las arquitecturas de cómputo se caracterizan por ser heterogéneas (procesadores multi-core, GPUs y TPUs) y estar implantados en entornos distribuidoss. Debido a esto, el rol de las abstracciones del SO es fundamental para el uso masivo de estos sistemas. Investigaciones recientes en el área de sistemas operativos Gill et al., 2024 Deng et al., 2024 destacan que la evolución de las interfaces de abstracción es importante para cerrar la brecha entre la complejidad del hardware emergente y las altas exigencias de rendimiento de las aplicaciones basadas inteligencia artificial a gran escala, por ejemplo.
