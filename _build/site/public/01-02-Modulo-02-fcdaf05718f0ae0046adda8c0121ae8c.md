# Estructura de los sistemas operativos

## Qué es un Sistema Operativo

Un sistema operativo es un software que maneja los recursos de un computador. Los componentes del HW proveen los recursos computacionales para las aplicaciones. Los programas y aplicaciones definen que recursos requieren. El SO define cómo esos recursos serán utilizados para resolver los problemas computaciones del sistema que está utilizando el computador.
