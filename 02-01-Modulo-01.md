## Argumentos

Desde el punto de vista del sistema operativo, el código de un proceso tiene un punto de entrada que se debe acceder para se pueda ejecutar. Este punto de entrada es la función main() del código y puede recibir los argumentos que fueron ingresados desde la {abbr}`CLI (Command Line Interface)`.

```
int main(int argc, char* argv[]) {
    // arg0 = argv[0] ...
    ...

    exit(EXIT_SUCCESS);
}
```

Los parámetros de la función `main()` son dos:
* `argc`: <b>arg</b>ument <b>c</b>ount.
* `argv`: <b>arg</b>ument <b>v</b>alue.

## Creación de procesos

El proceso que llama a `fork()` se denomina *Proceso Padre* y el nuevo proceso se denomina *Proceso Hijo*. El sistema operativo asigna un nuevo identificador de proceso (PID) al Proceso hijo y copia el espacio de direcciones, descriptores de archivos y registros del padre (ver {numref}`Figura %s <02-01-fork>`).

```{figure} images/02-01-fork.png
:label: 02-01-fork
:width: 60%
:align: center
```

La {numref}`Figura %s <02-01-op-fork-01>` muestra un trozo de código que uso la llamada a systema `fork()` para crear un proceso. Para el análisis, se asume que el PID del proceso es $\text{PID}_N$. Al comenzar su ejecución, el proceso ejecuta las líneas resaltadas, llegando a la instrucción `fork()`. Esta Syscall solicita la creación de un nuevo proceso al Sistema Operativo. Si la llamada es exitosa, el Sistema Operativo crea un proceso idéntico al original. 

```{figure} images/02-01-op-fork-01.png
:label: 02-01-op-fork-01
:width: 50%
:align: center
```

En este instante de tiempo, en la memoria del sistema computacional, está el proceso original (*Proceso Padre*) y el proceso creado (*Proceso Hijo*). Ambos procesos están realizando el lado derecho de la asignación (ver {numref}`Figura %s <02-01-op-fork-02>`).

```{figure} images/02-01-op-fork-02.png
:label: 02-01-op-fork-02
:width: 70%
:align: center
```

Una vez que cada proceso resuelve el lado derecho de la asignación, cada uno tiene un valor distinto asignado en la variables `res`. En el proceso original, el Sistema Operativo asigna el PID del proceso creado y en el nuevo proceso, asigna un valor 0 (ver {numref}`Figura %s <02-01-op-fork-03>`).

```{figure} images/02-01-op-fork-03.png
:label: 02-01-op-fork-03
:width: 100%
:align: center
```

En términos de código, se tiene la estructura de {numref}`Figura %s <02-01-op-fork-04>`). (1) La función `fork()` solicita al Sistema Opearivo reservar especio en la tabla de procesos para nuevo proceso. Si la operación falla, la función `fork()`retorna un valor negativo. Si el diseño del programa así lo requiere, el proceso debe terminar (2). Si el valor de retorno de `fork()` es no negativo, entonces significa que la operación `fork()` fue exitosa. En tal caso, si el valor de retorno es cero (3), entonces el proceso que está ejecutando el código es el Proceso Hijo. En caso contrario, el valor de retorno es mayor que cero (4), lo que implica que el proceso que está ejecutando el código es el proceso original.
